# 원본 모션 분석 — N 리스타일 기준

원본: KakaoTalk_Video_2026-09-18-21-34-27.mp4, 720×720, 약 20.455초.
AVFoundation의 프레임 요청 허용 오차를 0으로 설정하고 0.25초 간격으로 추출한 82개 프레임을 비교했다. 아래 시간은 이 표본에서 읽은 근사치이며 프레임 단위의 컷 경계 측정값은 아니다. 오디오는 분석하지 않았다.

## 구조

- 0–1.35초 근처: 나비 도판의 클로즈업. 카메라가 물러나면서 주변 표본이 더 보인다. 나비 날개의 국소 움직임.
- 1.35–2.65초 근처: 비스듬한 고지도. 미세한 이동. 앞 장면과 디졸브하지 않고 교체한다.
- 2.65–3.65초 근처: 도자기 도판. 고정 도판 위에서 느린 카메라 이동.
- 3.65–5.7초 근처: 열매 → 정원 평면도 → 건축 단면 → 새 도판. 컷 간격이 약 0.5초로 짧아진다.
- 5.7–8초 근처: 꽃무늬 → 다면체 → 알 → 미생물 → 악보 → 국기 → 장식 문양 → 옛 활자 → 표본. 0.25초 표본마다 이미지가 바뀌는 빠른 몽타주. 화면의 일부였던 윤곽이 숫자 5로 읽히기 시작한다.
- 8–13.2초 근처: 활자, 동전, 무화과 가지, 카드, 꽃, 우표, 지도, 청사진, 종이 조각, 클로버, 현미경, 버섯, 회로, 잎, 형광 세포, 엑스레이 물고기, 연결망, 시아노타입. 숫자의 위치와 전체 크기를 대체로 이어가는 매치 컷. 밝은 종이뿐 아니라 갈색·검정·청색·노랑 바탕으로 명도/색이 강하게 바뀐다.
- 13.2–13.9초 근처: 배양 접시의 5, 짧은 홀드로 속도 변화.
- 13.9–14.7초 근처: 꽃으로 된 5. 꽃잎이 떨어지면서 정지 화면이 살아난다.
- 14.7–16.2초 근처: 나비로 된 5. 나비가 날아오르면서 윤곽이 무너진다. 크기와 속도가 서로 다른 나비들이 깊이 방향으로 이동. 큰 전경 날개와 흐림이 컷을 가린다.
- 16.2–18.7초 근처: 주황 격자 배경 Fable 5. 나비가 빠져나가고 타이포그래피가 남는다.
- 18.7–20.2초 근처: 밝은 격자 배경 Claude.
- 마지막: 큰 나비가 다시 렌즈를 가린다.

## 기존 구현의 오류

1. N이 아닌 NOAH를 별도 브랜드 엔딩으로 사용했다.
2. 4초×6 구간은 원본의 가속/홀드 구조와 다르다.
3. 모든 장면에 같은 흩어짐/모임을 적용했다. 원본의 대부분은 하드 컷이다.
4. 같은 크기의 반복 스프라이트가 일정한 경로에 배치됐다. 원본은 소재마다 크기, 밀도, 글자 표현 방식이 다르다.
5. 종이색이 거의 고정되어 원본의 청사진·검정·색지 대비를 놓쳤다.
6. 소개 문구와 카드 UI가 영상을 페이지 속 삽화처럼 만들었다.
7. 이전 드문 프레임 추출은 기본 시간 허용오차를 사용해 일부 요청 시간과 실제 이미지 시간이 달랐다. 이번 분석은 허용오차 0으로 재검토했다.

## 수정 연출

20.455초 단일 정사각 영상. N 외 이름/로고 없음. 영상 밖 최소 재생 컨트롤.
확대 도판 탐색 → 간격이 짧아지는 컷 → N 위치를 잇는 고밀도 패턴 매치 컷 → 식물 N 홀드와 낙화 → 나비 N의 실제 분해/비행 → 색지 위 단독 N → 종이 위 단독 N → 전경 날개로 루프.
이미지 교체와 국소 움직임을 분리. 모든 컷에서 재조립하지 않는다. 아홉 가지 별도 N 도판과 크기/각도가 불규칙한 생물 표본 배치, 절차적 네트워크·미생물·악보 등을 사용한다.

## 追加: 30 Hz 전환 측정 및 모션 보정

64×64로 축소한 인접 프레임의 RGB 평균 차이를 1/30초 간격으로 비교했다. 주요 컷 후보는 1.50, 2.60, 3.60, 4.2667, 4.7667, 5.1667, 5.60, 5.9333초이며 후반 경계는 13.90, 14.7333, 16.1667, 18.60초다. 8–13초에는 약 0.10–0.17초 간격의 변화가 다수 검출된다. 움직임 자체도 차이를 발생시키므로 모든 후보를 정확한 컷으로 단정하지 않는다.

카메라 각도는 컷마다 고정, 중반 흔들림과 반복 이징 제거. 나비는 몸통을 유지한 좌우 날개 접힘, 시차를 둔 이륙, 개별 곡선 비행으로 변경. 원래 N의 나비가 주황 배경 위까지 지속. 전경 개체에만 흐림을 적용하며 화면 전체 방사형 블러는 삭제했다. 원작과의 차이를 줄이는 2.5D 구현이며 원본의 미확인 3D 리깅을 재현했다는 의미는 아니다.
