# 검증 기록 — 2026-10-02

실제 Codex 내장 브라우저, 1280×720 화면에서 로컬 HTTP 서버의 비교 모드를 검사했다. 왼쪽은 WebGL N, 오른쪽은 같은 video 시계를 사용하는 원본이다.

- 51개의 JPG가 모두 로드되고 WebGL 프로그램이 컴파일되어 렌더링됐다.
- 같은 프레임의 도판 인트로, 클로버/지도 몽타주, 꽃(350), 나비 초기(353), 접근(384), 주황 배경 진입(390), 엔딩 정지(437)를 직접 시각 비교했다.
- 나비 주변의 다른 표본 조각이 딸려 나오는 문제를 개체별 윤곽 마스크로 수정했다. 마스크 경계의 검은 선도 제거했다.
- 원본보다 작던 전경 나비의 접근 크기를 확대하고, 꽃잎 이동 거리를 늘렸다. 꽃잎은 N 꽃의 실제 위치에서 분리된다.
- 주황 글자 진입 높이와 밝은 글자의 짧은 정착, 마지막 축소를 추가 대조했다.
- 정상 1× 속도로 전체 20.455초 구간 및 다음 루프 진입을 실행했다. 0.5초 간격 44회 DOM 표본과 전환 구간 스크린샷을 기록했다 (`playback-samples.json`, `playback-*.jpg`). 이는 모든 화면을 연속 녹화한 기록은 아니다.
- 엔딩 보정 후 481프레임부터 정상 재생하여 종료 뒤 인트로로 돌아오는 것을 다시 확인했다.
- 관찰한 브라우저 콘솔에 JavaScript/WebGL 오류나 경고가 없었다.
- JavaScript 4개 파일 구문 검사 통과. 64개 구간의 연속성, 51개 필수 이미지 존재, 전체 비행 구간의 유한한 좌표/회전 값 검사 통과.

`final-comparison.jpg`는 최종 꽃잎 조정 후 350프레임의 실제 브라우저 화면이다.

정확한 컷 경계와 소재 대응을 구현했지만 모든 나비 개체의 경로가 원본과 일치하는 것은 아니다. 별도 3D 원본 리그가 없으므로 날개 관절, 깊이, 속도 곡선과 꽃잎의 연결 부위는 관찰 기반 근사다. 생성한 N 도판의 미세 삽화/여백 차이, 가까이서 보이는 표본 마스크/종이 보완, 엔딩 폰트 차이가 남는다. 다른 GPU·모바일 브라우저의 성능은 이번 검증에 포함하지 않았다.
